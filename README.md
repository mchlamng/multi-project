# AC Multivariable Calculus Final Project

![LaTeX](https://img.shields.io/badge/LaTeX-008080?logo=latex&logoColor=white)

This is the AC Multivariable Calculus Final Project presentation for Diego
Adams, Keshav Harpavat, Michael Meng, and Parrie Charoenrattanaruk, also know as
the Ice Cream Crew. We constructed a cone, and I typed up this presentation in
$\LaTeX$. This project file contains our construction process, documented; the
calculations, triple integral and Riemann sum, for the volume of our cone; and a
discussion of the volume values, along with percent error calculations that
treated the triple integral volume as the true value.
